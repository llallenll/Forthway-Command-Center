Enter the setup code

So nobody else who finds this new panel can claim it, setup needs the code the server printed when it started.

Find it with sudo cat /var/lib/fcc/setup-code (or journalctl -u fcc).

Name and address

Create a GitHub OAuth App

  1. Open github.com/settings/applications/new (or your organization's Settings → Developer settings → OAuth Apps).
  2. Application name: anything, e.g. Forthway Command Center.
  3. Paste the two addresses below, leave Enable Device Flow off, and click Register application.
  4. Copy the Client ID, click Generate a new client secret, and paste both here.
