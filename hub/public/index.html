Install the agent

    
Run this on the machine that runs this site.

  

    

    

      It installs Node and pm2 if that box does not have them, drops the agent in
      /opt/forthway-agent, starts it under pm2, and checks in here.
      Everything else is set from this card.
    

    

      Or set it up by hand
      

        
Hub URL

        
Site id

        
Token

      

      

        Put those in agent/agent.config.json beside copies of
        agent/ and shared/, then
        pm2 start agent/agent.mjs.

      Starting and stopping
      

        
        
      

      

        

          

          

            
Used only when pm2 has never seen this process, to register it.

        

      

      

        

          

          

            

        

      

      

        

        

      

      

        

          
The app is run as a child process, so the stop is certain — useful where there is no
            service manager. Its output streams into the console below.

      

      

        
One KEY=value per line, passed to the app and to every command run for it.

    


    

      Proving it came back
      

        

        

      

      

        Left blank these default to http://127.0.0.1:PORT/api/health and
        /api/version. The version check catches the nastiest failure there is:
        a stop that silently did nothing, so the old process keeps answering health checks perfectly
        while the new code never loads. See patches/ for the two routes.
